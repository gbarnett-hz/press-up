# Citation Style: Chicago Notes (17th ed.)

The newsroom cites per the **Chicago Manual of Style, 17th edition, notes system**, with notes collected as a numbered **References** section at the end of the piece. No inline links, ever - links live only in the References entries.

## In-text markers

- Every factual or assertive statement carries a superscript citation numeral: `^1^` in Pandoc markdown, rendering as ¹.
- Numbers run in **order of first appearance**: the first source cited is 1, the next new source is 2, and so on.
- A source cited again keeps its original number. Never renumber, never give a source a second number.
- The marker sits **after** punctuation: `...cool their streets.^7^`
- One statement drawing on several sources: `^1,4^` (both numerals superscripted, comma-separated).

## The References section

- Titled `## References`, placed after the body and figures, before nothing else.
- One entry per source, numbered in order of first appearance. Never alphabetical.
- Entries are **full notes**, Chicago style. Every entry ends with a URL (or DOI).

## Entry formats (CMOS 17th ed. notes)

| Source type | Format |
|---|---|
| News or magazine article | Author First Last, "Title of Article," *Publication*, Month Day, Year, URL. |
| Journal article | Author First Last, "Title of Article," *Journal* Volume, no. Issue (Year): pages, URL/DOI. |
| Book | Author First Last, *Title* (Place: Publisher, Year), page(s). |
| Web page | Author First Last, "Page Title," Site Name, Month Day, Year, URL. |
| Report | Author or Institution, *Title*, report type (Place: Publisher, Year), URL. |
| No author | Start with the title; use the site or institution as the publication where relevant. |
| Same author repeated | Repeat the full name; no "ibid." or three-em dashes in the References list. |

## Rules

- Full notes in the References section, never author-date, never shortened notes.
- Cite exactly what the researchers verified: no invented, guessed, or shortened URLs.
- A numeral supports the statement it follows; a claim a source cannot support fails adversarial review.
